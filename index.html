Echoes guide

Help & documentation

Start here

Run a battle in six steps

  1. Prepare a partyCreate your regular player characters under Parties.
  2. Fill the BestiaryUse the included creatures, import JSON, or create a monster.
  3. Add combatantsIn Combat, add a party, individual monsters, or a quick temporary entry.
  4. Set initiativeMonster initiative rolls automatically from Dexterity; type player results as rolled. Echoes sorts the order.
  5. Run turnsUse Next turn, adjust HP, and record conditions as play changes.
  6. Save useful setupsSave an encounter so the same roster is ready next session.

At the table

Combat

  • Initiative: select any initiative number and type a new value. The order updates automatically.
  • Turns: Next turn advances the active combatant. Passing the last entry starts a new round; the arrow moves back.
  • Player characters: directly edit current HP. Their name remains green and their active-turn border is green.
  • Monsters: drag the HP slider for large changes or use −10, −1, +1, and +10 for precision.
  • Bloodied: monster names turn red at half HP or below. Any combatant at 0 HP is struck through.
  • Conditions: select a combatant and manage conditions in the right details panel.
  • Edit or remove: the pencil edits that combat copy; × removes that exact entry. Combat edits never change the Bestiary unless Save to Bestiary is chosen.
  • Duplicates: copies of the same monster are numbered automatically.

Regular heroes

Parties

  • Create a party with New party.
  • Store character name, player name, class, maximum HP, and AC.
  • Edit a party to add, change, or remove characters. Use the far-right × to delete the party after confirmation.
  • Add a whole party from Parties or choose members through Add combatant.
  • A saved player character can only appear once in the active combat.

Preparation

Encounters

  • Build a combat roster, select Save encounter, and give it a name.
  • Select Edit on a saved encounter to load its roster into Combat. Add, remove, or alter combatants, then use Save encounter to update it.
  • Saving again with the same name also updates that encounter.
  • Starting a saved encounter restores maximum HP and clears old conditions.
  • Search by encounter, monster, character, player, or class.
  • Export JSON creates an editable backup. Import JSON restores it.
  • Starting an encounter replaces an existing combat only after confirmation.

Creature library

Bestiary

  • Search by name or type and filter by challenge rating.
  • Select a row to preview stats, movement, senses, traits, actions, and legendary actions.
  • + Combat adds a private copy to the active combat.
  • Edit changes the entry. Built-in creatures can be restored to their original statistics.
  • Edit as New creates a custom duplicate while keeping the original.
  • The far-right × asks for confirmation before deleting. Existing combat and encounter copies remain intact.
  • Import compatible monster collections with Import JSON.

Campaign characters

NPC Collection

  • NPCs are named campaign characters stored separately from reusable Bestiary creatures. Only the NPC name is required.
  • Create roleplay-only NPCs, link an existing Bestiary statblock, or create a new statblock that is automatically saved to the Bestiary and linked.
  • Deleting or unlinking an NPC never deletes its Bestiary statblock.
  • Portraits are resized before local storage. Voice Acting Note and Voice Acting Quote appear prominently in the editor and profile.
  • Race, class/profession, faction, locations and tags suggest values already used by the collection. Tags and additional locations support removable multi-value chips.
  • Search covers identity, organisation, locations, tags, summary and voice fields. Race, class, location, faction, tags and statblock status can be filtered together.
  • Relationships can link to another saved NPC or retain a manual name, relationship type and note.
  • From a profile, open, edit, replace or unlink the statblock, or add an NPC using its linked statblock to Combat.
  • NPC JSON import/export is available from the collection. Complete Echoes backups also include every NPC and portrait.

Rules reference

Spells

  • Search by name, school, class, or description.
  • Filter by level, school, casting time, and class.
  • Select a spell anywhere on its row to read the complete description.
  • Create a spell individually or import a JSON spell collection.
  • Known spell names in monster descriptions become clickable references.
  • DC values are automatically emphasized in descriptions.

Table tools

Dice roller

  • Open Dice roller directly below Spells in the left navigation.
  • Choose d4, d6, d8, d10, d12, d20, d100, or Custom (d2–d1000), then set the number of dice and an optional positive or negative modifier.
  • Select Roll dice, or press Enter while editing the dice count or modifier.
  • Dice notation such as 1d4 + 2 or 2d6 − 3 is clickable in monster and spell descriptions. Selecting it rolls immediately.
  • Every roll records its individual dice, modifier, total, time, and source ability or spell.
  • The most recent 200 rolls remain in the log and are included in complete Echoes backups. Use Clear log to remove them.

ChromeOS & desktop

Install Echoes

  • Open the securely hosted Echoes address in Chrome. A raw local file:// preview cannot be installed.
  • Open Data & backup and choose Install Echoes, or use Chrome’s Install option.
  • After installation, Echoes launches from the ChromeOS shelf or app launcher in its own standalone window.
  • The service worker keeps the application shell, Bestiary, and spell library available offline after the first successful load.
  • The same installation works in Chrome or Edge on Windows, macOS, and Linux.

More room

Screen controls

  • Use the arrow on the left panel to collapse navigation to icons.
  • Use the arrow beside combat details to collapse the right panel.
  • Both panel choices are remembered between sessions.
  • Choose Full screen for maximum visibility while standing at the table.
  • Details, traits, actions, and spell descriptions expand and collapse from their headings.

Local-first

Storage & backups

Browser storage is only Echoes’ working copy. Choose the exact external Echoes-library.json in any locally available or synchronised folder so permanent Bestiary entries, NPCs, parties, encounters, spells, and combat data live outside the browser.

Echoes remembers the file handle and updates that file automatically. Use Resume permission when Chrome requires access again; choose a different file only when you intend to change libraries.
